# "What's the Problem" — Danish Subtitle Review

This repo contains subtitle files for the video **"What's the Problem"** by Joe Bryan.
The Danish translation needs a review for accuracy, natural phrasing, and readability.

## Files

| File | Description |
|------|-------------|
| `4) English - YouTube native subtitles (3).srt` | Original English subtitles — use as reference |
| `4) JAKE-Dansk_korrigeret.srt` | Danish translation — this is what needs reviewing |

## How to suggest changes

1. Open `4) JAKE-Dansk_korrigeret.srt` in this repo
2. Click the **pencil icon** (Edit this file) in the top right
3. Make your corrections directly in the browser
4. At the bottom, select **"Create a new branch"** and click **"Propose changes"**
5. On the next screen, click **"Create pull request"**

This creates a Pull Request where every changed line is highlighted. You can also leave comments on specific lines explaining your reasoning.

## Review focus areas

- Accuracy compared to the English source
- Natural, spoken Danish (these are subtitles, not written prose)
- Timing-friendly phrasing — shorter is often better
- Consistent terminology throughout

## SRT format

Each subtitle block looks like this:

```
1
00:00:20,982 --> 00:00:21,440
[Musik]
```

Only edit the **text line(s)** — do not change the sequence numbers or timestamps.
